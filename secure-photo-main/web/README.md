# Веб-страница отправителя

Файлы статические и не требуют сборки. Сервер страницы должен отдавать их под `/s/` по HTTPS.

Перед отправкой изображение декодируется через `createImageBitmap`, поворачивается с учётом EXIF, уменьшается до 2048 px, перекодируется в JPEG quality 0.85 и затем шифруется WebCrypto. Сервер получает только payload из `PROTOCOL.md`.

Ручная проверка на iPhone Safari:

1. Открыть ссылку с `#r=...&k=...&pk=...`.
2. Выбрать фото и проверить preview.
3. Отправить с разными лимитами просмотров и TTL.
4. На серверном диске убедиться, что blob не распознаётся как JPEG (`file` не должен определить JPEG).
5. Перезагрузить страницу — параметры должны восстановиться из `localStorage`.
